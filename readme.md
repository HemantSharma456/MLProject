# 🚀 AI Resume Evaluator

An intelligent web application that analyzes resumes and provides actionable feedback using AI.  
It helps users improve their resumes by evaluating structure, skills, keywords, and overall quality.

---

## 📌 Features

- 📄 Upload Resume (PDF/DOCX)
- 🤖 AI-powered Resume Analysis
- 📊 Section-wise Feedback (Skills, Experience, Projects, etc.)
- 🎯 ATS Optimization Suggestions
- 🏢 Suggested Companies based on Resume (optional feature)
- ⚡ Clean UI with loading states and result cards
- 📥 Download Evaluation Report

---

## 🛠️ Tech Stack

### Frontend
- React.js

### Backend
- Node.js

### AI / Processing
- OpenAI API / Claude API
